# React HOL 13 - Blogger App

Demonstrates conditional rendering techniques: if-else, ternary operator, logical &&, and element variables.
Components: BookDetails, BlogDetails, CourseDetails — all using map() with keys.

## How to Run
```bash
npm install
npm start
```

## Features
- **BookDetails** — if-else via element variable, ternary for availability badge
- **BlogDetails** — if-else for filter label, ternary for published status
- **CourseDetails** — logical && for conditional badge, ternary for free/paid
- All lists rendered with map() and unique keys
